**Honor PC Helper** - лёгкая замена HONOR PC Manager с открытым исходным кодом: утилита управляет железом ноутбуков HONOR MagicBook из системного трея - **ограничение заряда батареи**, **подсветка клавиатуры**, **режим производительности**, **виброотклик и жесты тачпада**. Работает напрямую через фирменный WMI-интерфейс BIOS HONOR, тот же, что использует PC Manager, так что аппаратные настройки доступны без установки фирменного комбайна.

Один portable-файл `.exe`: без установки, без служб в фоне, без телеметрии.

## Возможности

- **Ограничение заряда батареи** - порог зарядки (например, 70-80%) продлевает срок службы аккумулятора, если ноутбук постоянно в розетке
- **Подсветка клавиатуры** - включение и выключение, таймаут погасания, расписание автовключения по вечерам; уровень восстанавливается после сна и modern standby
- **Режим производительности** - переключение между умным (сбалансированным) и производительным режимом без запуска PC Manager
- **Управление драйверами** - автоматическое определение любой поддерживаемой модели ноутбука HONOR и безопасная загрузка свежих или отсутствующих драйверов из официальных сервисов HONOR
- **Обновление приложения** - проверка новых версий Honor PC Helper в GitHub Releases и автоматическая замена portable-файла
- **Мониторинг железа** - температуры, обороты вентиляторов и мощность заряда/разряда в ваттах прямо в подсказке трея
- **Тачпад** - интенсивность виброотклика, жесты по краям (яркость слева, громкость справа), изменение яркости экрана движением по левому краю со штатным индикатором Windows
- **Автозапуск** - старт вместе с Windows
- **Языки интерфейса** - русский, английский и упрощённый китайский, выбираются автоматически по языку Windows

## Требования

- **Windows 10 или 11, x64**
- Ноутбук **HONOR** с WMI-интерфейсом BIOS - он есть у линейки MagicBook (MagicBook 14, 15, 16, X14, X16, Pro, Art)
- Среда .NET не нужна: сборка из релиза самодостаточная
- HONOR PC Manager устанавливать и держать запущенным **не требуется**

Набор функций зависит от модели и версии BIOS: виброотклик доступен только на моделях с force pad, часть машин отдаёт меньше датчиков. Неподдерживаемые пункты в меню трея не показываются.

## Скачать и запустить

1. Скачайте `HonorPCHelper.exe` из [последнего релиза](https://github.com/Wintego/Honor-PC-Helper/releases/latest).
2. Запустите. Установка и зависимости не нужны - значок появится в системном трее.
3. Кликните по значку в трее, чтобы открыть меню.

При первом изменении аппаратной настройки Windows запросит права администратора, чтобы создать служебную задачу. Дальше приложение работает без запросов UAC.

Для проверки драйверов откройте пункт "Драйвера" в меню трея. Приложение сопоставит ноутбук с официальными каталогами HONOR и выделит свежие или отсутствующие пакеты. Нажмите на выделенную версию, чтобы проверить и скачать установщик; запуск установки остаётся под вашим контролем.

## Частые вопросы

### Как ограничить заряд батареи на HONOR MagicBook без PC Manager?

Откройте меню трея, выберите пункт «Батарея» и задайте диапазон заряда. Пороги записываются через WMI-интерфейс BIOS HONOR и сохраняются после перезагрузки - так же, как если бы их выставил PC Manager.

### Как включить подсветку клавиатуры на HONOR MagicBook?

В подменю «Подсветка клавиатуры»: включение и выключение, таймаут погасания. Там же расписание, которое зажигает подсветку автоматически по вечерам.

### Чем заменить HONOR PC Manager?

Этим проектом. Honor PC Helper закрывает аппаратные настройки и обновление драйверов одним portable-файлом, без собственного установщика и фоновых служб. Мультиэкран с телефоном не поддерживается.

### Можно ли удалить HONOR PC Manager и пользоваться только этой утилитой?

Да, если не нужен MagicRing. Записанные PC Manager значения (пороги заряда, таймаут подсветки) хранятся в BIOS и продолжают действовать; Honor PC Helper читает их через тот же WMI-интерфейс, а свежие драйверы получает из официального сервиса обновлений HONOR.

### Нужны ли права администратора?

Один раз - чтобы создать служебную задачу, которая выполняет аппаратные команды. В повседневной работе приложение обходится без повышения прав.

### На моей модели часть пунктов меню отсутствует

Эти функции не отдаёт BIOS вашего ноутбука. Датчики температур и вентиляторов, виброотклик и жесты тачпада отличаются от модели к модели и от прошивки к прошивке.

## Сборка из исходников

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0):

```powershell
.\build.ps1
```

Готовый файл появится в `dist\HonorPCHelper.exe`.

---

Проект не связан с HONOR и не поддерживается компанией. HONOR и MagicBook - товарные знаки соответствующих владельцев.
